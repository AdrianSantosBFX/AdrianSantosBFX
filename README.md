## About me

I'm a developer based in Brazil, building backend APIs and desktop tools for everyday business problems. My work connects software development with fiscal workflows: reading structured files, organizing documents and making information easier to review.

I work with **Python, FastAPI and Java**, with an emphasis on clear workflows, local data processing and useful results.

## What I build

- **Backend & APIs** — services and integrations that connect systems and reduce repetitive work.
- **Business automation** — tools that turn manual routines into repeatable processes.
- **Fiscal desktop tools** — applications for exploring SPED data and organizing Brazilian fiscal documents.
