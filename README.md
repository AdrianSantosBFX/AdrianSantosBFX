## About

I'm **Adrian Santos**, a developer based in Brazil. I build tools that organize information, reduce repetitive work and make business workflows easier to run and review.

My work connects software development with practical problems: exploring fiscal data, organizing documents, managing sales opportunities and structuring project delivery. I use **Java, Python and JavaScript** across backend APIs, desktop applications and web interfaces.

## How I build

- **Clear workflows:** separate steps, responsibilities and states to make tools easier to use and maintain.
- **Data with context:** distinguish declared values, estimates and information that has not been provided.
- **Local processing where appropriate:** keep files and storage close to the people using the tool.
- **Verifiable changes:** use synthetic examples, tests and setup instructions to support further development.
